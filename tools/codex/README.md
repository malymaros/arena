# CODEX - referenčné obrázky

`balance-full.png` = celý obrázok „svetlo vs tma" zo spodku zakázanej (HIDDEN) strany CODEXu, 3× zväčšený
(jin-jang, biela a čierna sviečka). V hre z neho odtrhnutý list zakrýva pravú časť (čiernu sviečku a hviezdy) -
kreslí ho vždy celý `drawBalance` v `public/client/codex.js`, odrezáva ho len prekrytie `.cx-torn`. Keď sa raz
strana doplní (list už nebude odtrhnutý), stačí odstrániť trhlinu a obrázok bude celý.
